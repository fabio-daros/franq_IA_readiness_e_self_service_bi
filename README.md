# FinLend Credit Intelligence

Technical case for a Data Analyst position focused on Self-Service BI, credit risk analysis and AI Readiness.

## Architecture

The project follows a lightweight Medallion Architecture:

- Bronze: raw Lending Club data.
- Silver: cleaned and standardized loan-level data.
- Gold: business-ready datasets and official metrics.

## Deliverables

- Looker Studio dashboard
- Python statistical analysis notebook
- Generative AI validation report
- Reproducible Bronze to Silver to Gold pipeline
